1장 운영체제 개요

운영체제가 무엇이고, 무슨 일을 하며, 어떻게 발전해 왔는지

컴퓨터 자원→운영체제가 관리·보호→프로그램이 편하게 실행

1. 운영체제란?

운영체제(OS) = 컴퓨터 전체(CPU·메모리·저장장치 등 자원)를 관리하고, 응용 프로그램이 실행될 환경을 제공하는 소프트웨어.

  • 소프트웨어 = 응용 프로그램(한글, 워드, 웹 브라우저처럼 특정 일을 함) + 시스템 소프트웨어(하드웨어와 응용 프로그램을 관리).
  • 시스템 소프트웨어 = 운영체제 + 유틸리티(백신처럼 OS를 보조). 유틸리티는 OS 구성 요소가 아님!

비유: OS는 건물 관리실. 입주자(프로그램)는 보일러실(하드웨어)에 직접 못 들어가고, 관리실 창구(시스템 호출)에 신청만 할 수 있어요.

2. 역할 ↔ 목표 (짝으로 외우기)

역할쉬운 뜻목표
자원 관리CPU·메모리를 효율적으로 나눠 줌효율성
자원 보호다른 프로그램이 함부로 못 건드리게 막음안정성
하드웨어 인터페이스새 장치를 쉽게 붙일 수 있게 함확장성
사용자 인터페이스사람이 쓰기 쉬운 화면·명령 제공편리성

"복잡성"은 목표가 아님 (연습문제 단골 함정).

3. 운영체제의 구조

  • OS 구성 = 커널(핵심 기능: 프로세스·메모리·파일·입출력 관리) + 사용자 인터페이스 + 디바이스 드라이버.
  • 시스템 호출 = 커널에 자발적으로 들어가는 유일한 방법. (printf도 속에서는 시스템 호출을 부름)
  • API = 응용 프로그램을 만들 수 있게 제공하는 함수 모음.
  • 연결 관계: 응용 프로그램 ↔ 커널 = 시스템 호출 / 커널 ↔ 하드웨어 = 디바이스 드라이버
커널 구조특징
단일형한 덩어리. 빠르지만 한 곳이 고장 나면 전체에 영향, 수정 어려움
계층형비슷한 기능을 층으로 묶음(윈도우 등). 층 사이 통신 비용
마이크로커널엔 최소 기능만. 안정적이지만 모듈끼리 통신이 많음 (마하 커널)

4. 발전 순서 = 앞 단계의 불편을 고친 순서

하드와이어링→폰노이만 구조→일괄 작업→대화형→시분할→분산·클라이언트-서버·P2P→클라우드·사물 인터넷
  • 하드와이어링: 전선을 바꿔 끼워 프로그래밍. → 폰노이만 구조: 프로그램을 메모리에 올려 실행.
  • 일괄 작업 시스템: 작업을 모아 한 번에 하나씩 → 멀티프로그래밍 수준 = 1.
  • 대화형 시스템: 키보드·모니터 발명으로 주고받기 가능.
  • 시분할 시스템: CPU 시간을 잘게 나눠 여러 작업을 번갈아 실행 = 다중 프로그래밍·다중 사용자. 일괄 작업과 반대 개념.
  • 실시간 시스템: 정해진 시간 안에 반드시 처리. 임베디드 시스템: CPU·메모리·화면이 작고 특정 작업만(가전제품 등).
  • 클라이언트-서버: 서버 과부하 → P2P로 해결(서버는 목록만, 데이터는 사용자끼리). 사물 인터넷: 가전이 인터넷에 연결.
  • 모바일: 안드로이드 = 리눅스 커널, iOS = 마하 커널(ARM 특화). 리눅스 = 무료 배포 철학(오픈 소스).
★ 시험 포인트
  • 역할 ↔ 목표 짝 맞추기, "OS 목표가 아닌 것 = 복잡성"
  • 커널에 자발적으로 들어가는 유일한 수단 = 시스템 호출 / 커널 ↔ 하드웨어 = 디바이스 드라이버
  • OS 구성 요소가 아닌 것 = 유틸리티
  • 멀티프로그래밍 수준 1 = 일괄 작업, 서버 과부하 해결 = P2P
근거: 수업 교재 1장 본문·장 끝 요약·연습문제, 연습문제 해답(홀수). 형광펜 = 꼭 외울 것, 주황 상자 = 계산, 점선 상자 = 시험 포인트.
