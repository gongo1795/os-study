중간 + 기말 범위

5장 CPU 스케줄링

준비 큐에서 누구에게 먼저 CPU를 줄지 정하는 방법 + 평균 대기 시간 계산

FCFS→ 콘보이 효과 →SJF→ 기아 →HRN(에이징)|RR→SRT→MLQ→MLFQ

1. 스케줄링 단계와 목표

  • 고수준: 작업을 받을지 말지(전체 작업 수 조절). 중수준: 일부 프로세스를 보류시켜 과부하 방지. 저수준: 지금 누구에게 CPU를 줄지.
  • 목표: 공평성, 효율성, 안정성, 확장성, 반응 시간 보장, 무한 연기 방지. "무조건 공평"은 아님(우선순위 고려).
  • 선점형: 실행 중인 걸 중단시키고 다른 걸 실행 가능(문맥 교환 오버헤드 큼). 비선점형: 한 번 CPU를 받으면 끝까지.
  • 우선순위 높은 쪽: 커널 > 사용자, 전면 > 후면, 대화형 > 일괄, 입출력 집중 > CPU 집중. (입출력 집중을 먼저 → 금방 CPU를 내놓고 입출력하러 가서 CPU·입출력장치가 같이 일함)

2. 알고리즘 한눈에

구분알고리즘방식문제·특징
비선점FCFS (선입선출)온 순서대로콘보이 효과(긴 작업 뒤에 줄줄이 대기)
SJF (최단 작업 우선)실행 시간 짧은 것 먼저기아 현상, 작업 길이를 미리 알아야 함
HRN (최고 응답 우선)(대기 + 실행) ÷ 실행 이 큰 것 먼저기다린 시간 반영 = 에이징으로 기아 완화
선점RR (라운드 로빈)FCFS + 타임 슬라이스씩 돌아가며우선순위 없음. 타임 슬라이스가 너무 작으면 문맥 교환 ↑
SRT (최소 잔여 시간)남은 시간이 가장 짧은 것 먼저(수시로 교체)기아 가능
MLQ (다단계 큐)우선순위별 큐 여러 개고정 우선순위(큐 이동 X)
MLFQ (다단계 피드백 큐)CPU를 쓸 때마다 아래 큐로변동 우선순위, 아래 큐일수록 타임 슬라이스 ↑, 맨 아래는 FCFS

"기아가 생기는 비선점 알고리즘" = SJF (SRT는 선점이라 아님).

3. 멀티프로세서 스케줄링

  • 프로세스 선호도: 같은 프로세스의 스레드를 같은 코어에서 계속 실행(캐시 재사용).
  • 작업 훔치기: 스레드가 많은 큐에서 빈 큐로 나눠 줌.
🧮 계산: 평균 대기 시간
  1. 간트 차트 그리기: 누가 몇 ms부터 몇 ms까지 CPU를 썼는지 막대로.
  2. 각자 대기 시간 = (CPU를 처음 받은 시각 − 도착 시각). 여러 번 끊기면 기다린 구간을 전부 더함.
    한 번에 구하는 공식: 대기 시간 = 끝난 시각 − 도착 시각 − 실행 시간
  3. 평균 대기 시간 = 대기 시간의 합 ÷ 프로세스 수. (반환 시간 = 대기 시간 + 실행 시간)

교재 예제: P1(도착 0, 실행 30), P2(도착 3, 실행 18), P3(도착 6, 실행 9), 단위 ms

알고리즘간트 차트대기 시간평균
FCFSP1 0–30 → P2 30–48 → P3 48–570 + 27 + 42 = 6923
SJFP1 0–30 → P3 30–39 → P2 39–570 + 36 + 24 = 6020
HRN30ms에 P2 = (27+18)/18 = 2.5, P3 = (24+9)/9 ≈ 3.67 → P3 먼저6020
RR (TS 10)P1 0–10 → P2 10–20 → P3 20–29 → P1 29–39 → P2 39–47 → P1 47–5727 + 26 + 14 = 6722.33
SRT (TS 10)P1 0–10 → P3 10–19 → P2 19–37 → P1 37–5727 + 16 + 4 = 4715.67

RR 확인: P1은 10–29(19) + 39–47(8) 기다림 = 27, P2는 3–10(7) + 20–39(19) = 26, P3는 6–20 = 14.
SRT 확인: 10ms에 남은 시간 P1 20, P2 18, P3 9 → P3. 19ms에 P1 20, P2 18 → P2.

👉 숫자만 바꾼 연습문제는 문제풀이 페이지의 계산 문제에 있어요.

★ 시험 포인트
  • 선점/비선점 분류, 콘보이 = FCFS, 기아 비선점 = SJF, 기아 해결 = 에이징(HRN)
  • MLQ 고정 vs MLFQ 변동, 프로세스 선호도 vs 작업 훔치기
  • 평균 대기 시간 계산(위 표 그대로 손으로 다시 풀어 보기)
