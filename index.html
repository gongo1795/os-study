중간고사 범위 (1~5장)

기말에도 포함돼요. 문제는 1~5장 합본 한 페이지에 중요한 것만 모았어요.

1~5장 합본 문제 풀기

기말 추가 범위 (6장~)

기말 비중이 큰 부분이에요. 장마다 문제 페이지가 따로 있고, 계산 문제는 각 페이지 맨 뒤에 있어요.

문제 출처: 교재 각 장 연습문제. 홀수 객관식 정답은 연습문제 해답 파일 기준, 짝수·서술형은 교재를 보고 직접 푼 풀이(“직접 풀이” 표시)예요. ‘교재 예제로 만든 연습문제’는 교재 예제 숫자나 새 숫자로 만든 계산 연습이에요.
