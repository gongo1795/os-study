# os-study

운영체제 수업 공부용 사이트입니다. 장별 **한 장 요약**과 **문제풀이 페이지**가 있어요.

## 여는 방법

- 저장소를 내려받은 뒤 `index.html`을 브라우저로 열면 됩니다. (서버 없이 파일로 열어도 동작)
- 풀이 기록, ⭐ 중요 표시, 📝 메모는 **그 브라우저에만** 저장됩니다(localStorage).
  다른 기기로 옮기거나 브라우저 데이터를 지우기 전에는 문제 페이지 아래 **기록 백업 받기**로 파일을 받아 두고, 옮긴 곳에서 **백업 불러오기**를 누르세요.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 홈 (장 목록, 진행 상황) |
| `summary/chNN.html` | N장 한 장 요약. 계산은 주황 상자, 시험 포인트는 점선 상자 |
| `quiz/mid-1-5.html` | 1~5장 합본 문제 (중요 문제만, 계산은 맨 뒤) |
| `quiz/chNN.html` | 6장부터 장별 문제 (계산은 맨 뒤) |
| `data/chNN.js` | 문제 데이터 |
| `assets/` | 공통 스타일, 문제풀이 엔진, 장 목록 |

## 새 장 추가하기 (예: 11장)

1. `data/ch11.js` 만들기 (다른 장 파일과 같은 형식, `ch: 11`)
2. `quiz/ch10.html`을 복사해 `quiz/ch11.html`로 만들고 `data-sets="11"`, 스크립트 경로 `../data/ch11.js`, 제목을 바꾸기
3. `summary/ch11.html` 만들기
4. `assets/chapters.js`에 한 줄 추가:
   `{ ch: 11, title: "...", summary: "summary/ch11.html", quiz: "quiz/ch11.html", range: "final" }`

## 문제 표시

- **해답 파일 정답**: 연습문제 해답(홀수) 기준
- **직접 풀이(해답 없음)**: 짝수·서술형. 교재를 보고 푼 풀이라 틀릴 수 있어요
- **교재 예제로 만든 연습문제**: 계산 연습용으로 만든 문제
- **확인 필요**: 해답과 교재가 다르거나 문제에 오타가 있는 경우. 해설 아래 ⚠ 메모를 보세요

해답 파일과 교재는 저작권 문제로 이 저장소에 올리지 않았습니다.
